# 07 — Operação e problemas

A Federação deve controlar domínio, contas Sanity, Cloudflare, Asaas, Cora, hospedagem do Sistema 2, faturamento e cofre de segredos. Nomeie uma pessoa responsável por incidentes, renovação de credenciais, dependências e backups do PostgreSQL. Hospedagem do NestJS, painel e banco ainda não está definida; escolha serviços que ofereçam HTTPS, PostgreSQL persistente, backup/restore, variáveis secretas, logs, agendamento do processo e rede entre painel/API. Teste restauração de backup em ambiente isolado. A operação não é livre de manutenção.

| Sintoma                | Verificação e ação                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CTA indisponível       | Confira `PUBLIC_ASAAS_AFFILIATION_URL`/`PUBLIC_ASAAS_DONATION_URL`, protocolo HTTPS e hostname Asaas. Refaça o build Astro. Para filiação, só ative após confirmar Pix recorrente no Sandbox.                                               |
| Webhook sem eventos    | Verifique URL pública HTTPS `/webhooks/asaas`, sem redirect, logs de entrega no Asaas e health check do backend. Asaas requer HTTP 200. Se a fila foi interrompida, corrija antes de reativar; o provedor retém eventos por tempo limitado. |
| Token inválido (401)   | Compare `ASAAS_WEBHOOK_TOKEN` no backend com o `authToken` da configuração Asaas. Ele é diferente de `ASAAS_API_KEY`. Reinicie backend após alterar. Nunca registre os valores em logs.                                                     |
| Falha API Asaas        | Confira `ASAAS_ENV`, chave correta para esse ambiente, limites 429 e logs do processo NestJS. GET tem tentativas com espera; não repita criação financeira às cegas.                                                                        |
| Origem desconhecida    | Em `GET /events`, localize `UNRESOLVED`. Confirme se `paymentLink` corresponde a um `ResourceOrigin` ou se a assinatura foi vinculada. Como ADMIN, execute conciliação e depois reprocessamento. Não associe por nome/e-mail/valor.         |
| Erro CORS ou cookie    | Veja a URL exata do painel em `FRONTEND_ORIGIN`, `VITE_API_URL`, HTTPS e SameSite/Secure. Faça login de novo; `GET /auth/me` renova token CSRF, mutações enviam `X-CSRF-Token`.                                                             |
| Banco indisponível     | `GET /health/ready` falha. Veja `docker compose -f sistema-2/docker-compose.yml ps`, credenciais/porta em `DATABASE_URL` e logs do PostgreSQL. Restaure backup se necessário; não use reset como correção.                                  |
| Sincronização atrasada | Consulte `GET /reports/summary` (última conciliação) e `GET /events`. Reprocessar exige ADMIN, CSRF e registro de auditoria. Confirme que uma única instância recebeu o evento e que a caixa de entrada voltou a processar.                 |

O backend grava eventos no PostgreSQL e expõe somente estados/resumo em `/events`; payload com dados pessoais fica no banco protegido. Logs de execução ficam no terminal local ou no coletor do provedor de hospedagem a definir. O painel não contém dados de demonstração: se aparecer vazio, confira o banco e os eventos, não faça cadastro manual como substituto da integração.

As notificações de cobranças ficam com o Asaas; verifique na conta os canais habilitados, frequência, tarifas e um envio no Sandbox antes de ativar canais pagos. [Notificações Asaas](https://docs.asaas.com/docs/notificacoes). Não há serviço próprio de e-mail/SMS/WhatsApp. Para a conta Cora PJ, confirme titularidade, habilitação Asaas, disponibilidade de saldo, prazo, tarifa, limites e possibilidade de repasse nativo. A instituição precisa aceitar o trajeto **pagadora → Asaas → Cora**; Sandbox não comprova liquidação bancária. Nenhuma transferência por API foi implementada. Não ative produção sem homologação Pix, webhook, proteção de dados, backup e repasse.
